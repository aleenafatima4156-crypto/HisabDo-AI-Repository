# Faster Access to HisabDo Information


## How It Helps the User

Users can ask questions in natural language and receive relevant information about HisabDo features, functions, and common tasks.

**Example:** “How can I add an expense?”

## User Benefit Flow

User Question → AI Understands Request → Relevant HisabDo Information → User Gets Quick Answer

## Expected Impact

- Reduces time required to find information.
- Reduces unnecessary navigation.
- Helps users understand HisabDo features more easily.
- Provides quick access to relevant support information.
- Can reduce the need for human support for common questions.

## Conclusion

Faster access to information helps users solve common questions efficiently and use HisabDo with less confusion and searching.
