# Easier Feature Discovery


## How It Helps the User

Users can ask what feature they need for a particular task instead of searching through menus.

**Example:** “Where can I manage my expenses?”

The system can guide the user toward the Expenses feature.

## User Benefit Flow

User Need → User Asks a Question → AI Understands the Request → Relevant Feature Identified → User Discovers the Feature

## Expected Impact

- Makes HisabDo features easier to discover.
- Reduces menu searching.
- Helps new users understand where features are located.
- Reduces confusion about which feature to use.
- Helps users reach relevant functionality faster.

## Conclusion

Easier feature discovery makes navigation simpler and reduces time spent searching for features.
