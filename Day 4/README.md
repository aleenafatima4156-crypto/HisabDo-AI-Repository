# Day 4 - Student Performance Prediction

## Problem Statement
The goal of this project is to predict whether a student will pass or fail based on academic performance data.

## Features Used
- Attendance
- Assignment Score
- Midterm Score
- Final Score

## Model Used
Logistic Regression

## Steps Performed
1. Loaded the dataset using Pandas
2. Created a Pass/Fail target column
3. Split the data into training and testing sets
4. Trained a Logistic Regression model
5. Made predictions
6. Evaluated the model using Accuracy, Confusion Matrix, and Classification Report
