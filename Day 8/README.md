# Day 8 – AI/ML Capstone Project

## AI/ML Opportunities for HisabDo

This project identifies five practical AI/ML use cases for HisabDo:

1. Smart Expense Categorization
2. AI Financial Assistant
3. Receipt/OCR Processing
4. Financial Insights and Anomaly Detection
5. Smart Payment Reminders

## Top 2 Features

### Smart Expense Categorization
User → Application → AI Categorization API → ML Model → Category → Database → Analytics

### AI Financial Assistant
User → Application → AI Assistant API → Authorized Financial Data → RAG/Analytics → LLM → Response

## Conclusion
Smart Expense Categorization can reduce manual work and improve analytics. An AI Financial Assistant can help users understand their financial information through natural-language questions.
