# Selected AI Feature Documentation

## Feature Name
AI-Powered Expense Categorization

## Project
HisabDo

## AI Technique
Machine Learning / Natural Language Processing (NLP)

## Technology
- TF-IDF Vectorization
- Logistic Regression
- Python
- Flask REST API

## Input
Expense description entered by the user.

## Output
Predicted expense category and confidence score.

## Purpose
The feature automatically categorizes user expenses based on their descriptions, reducing manual effort and making expense recording faster and easier.

### Example
**Input:** `I bought pizza for dinner`

**Expected Category:** `Food & Groceries`

**Expected Output:** Category + confidence score
