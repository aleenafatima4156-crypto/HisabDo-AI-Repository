# Technology Stack

| Layer | Technology | Purpose |
|---|---|---|
| Frontend | HisabDo Website / Mobile App | Collect expense input |
| Backend | Python + Flask | REST API |
| Machine Learning | Scikit-learn | Model training and prediction |
| Text Processing | TF-IDF Vectorizer | Convert text into numerical features |
| ML Algorithm | Logistic Regression | Expense classification |
| Data Handling | Pandas | Dataset processing |
| Model Storage | Joblib | Save/load trained components |
| API Format | JSON | Data exchange |
| Testing | Postman | API testing |

## Software Requirements

- Python 3.x
- Flask
- Pandas
- Scikit-learn
- Joblib
- VS Code / Jupyter Notebook
- Postman
